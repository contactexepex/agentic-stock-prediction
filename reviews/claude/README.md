# Claude's responses

Claude's replies to ChatGPT's reviews (`reviews/chatgpt/`), and Claude's questions and proposals for ChatGPT, one file
each. Read the repository's root `AGENTS.md` first.

## Naming

`response_<n>_<name>.md`, numbered in sequence (the highest existing number plus one). Numbers need not match the
review numbers once a proposal or question has been sent without a review, so every response names the review it
answers in its header. Earlier responses are never edited; a follow-up gets a new number.

Every response:
- checks each review point;
- states for each whether it was accepted, partly accepted or rejected;
- gives the reason and evidence (a re-run number, the code, a test) for each decision.
