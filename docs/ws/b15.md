# B15, Company pages UI (Wave 4)

## Scope
The Next.js pages 03-company (`/{market}/stocks/{ticker}`, reading `/api/v1/markets/{m}/stocks/{t}`), its per-day
call history (`/{market}/stocks/{ticker}/lifecycle/{date}`, reading `.../stocks/{t}/lifecycle/{date}` plus the company
page) and 04-stock-strategies (`/{market}/stocks/{ticker}/strategies`, reading `.../stocks/{t}/strategies`), built
from the approved mockups (`design/mockups/03-company/`, `04-stock-strategies/`) on B12's endpoints inside B7's app
shell; the company page's watchlist actions go through B11's command routes. Branch `build/b15-company-ui`.

## Files
Route folders (B15 owns them; B7's layout, docs/ws/b7.md):
- `web/app/(cockpit)/[market]/stocks/[ticker]/page.tsx` (server component, metadata) and `_parts/`:
  `company-page.tsx` (the page: usePage + PageState, the sections in the mockup's order), `decision.tsx` (company line
  and the "at a glance" card), `price-chart.tsx` (the SVG price chart: candles, volume, the reference strategy's fan,
  targets, target spread, trade marks, hover and arrow-key reading), `trades.tsx` (open trades with the latest check;
  settled trades with the "why" bars), `cards.tsx` (EOD analyst notes, news with status, results digest, coming events,
  watchlist settings with the links to the call history), `actions.tsx` (Change amount / Deactivate / Reactivate
  confirm dialog), `context.ts`, `labels.ts` (reason codes, event types, note kinds), `legend.tsx`, `company.css` (the
  mockup's page CSS, minus the mockup-only example picker).
- `.../stocks/[ticker]/strategies/page.tsx` and `_parts/strategies-page.tsx`, `_parts/strategies.css` (04).
- `.../stocks/[ticker]/lifecycle/[date]/page.tsx` and `_parts/lifecycle-page.tsx`, `_parts/lifecycle.css` (no mockup:
  built from the 03 page's parts).
Pure logic with node tests (`npm test` covers `lib/**/tests`): `web/lib/company-pages/` `types.ts` (the payload fields
read), `company-logic.ts` (open-trade sums, settled summary, "why" segments, trade marks, next event, range bands,
call-history dates, prediction paths), `chart-geometry.ts` (price chart scales, fan, targets, spread, month ticks; ticks
from B7's `lib/ui/scales.ts`), `strategies-logic.ts` (ranking order, best row, expected gain in money, agreement per
horizon), `commands.ts` (preview then submit of a company command with one Idempotency-Key, pending words);
`tests/logic.test.ts`, `tests/commands.test.ts`.
UI cases: `web/tests/ui/cases/company.mjs` (B7's harness). No shared file changed; no dependency added.

## Contract
No API or data change. Reads only `/api/v1` (B12's routes; windows are B12's: news 30 days / newest 50, events 60
days, bars 250 sessions, owner 2026-10-08). Writes only through B11's `POST .../companies/preview` and
`.../companies/commands` (tools `set_paper_amount`, `deactivate_company`, `reactivate_company`; the same
Idempotency-Key for both steps, `confirmed_summary` = the preview's summary); a request shows as pending until the next
import. Delete is not offered here (the Companies page's typed confirmation, F8). Links: `lifecyclePath`,
`companyPath`, `stockStrategiesPath` of `lib/ui/routes.ts`; a strategy name on page 04 links to
`/{market}/strategy-lab#<id>`.

Differences from the mockups, all because the app has real routes or real data:
- No example-company picker (mockup only, said so in the mockup).
- The confirm dialogs show the server's own summary before Record (the mockup recorded a local pending line).
- The watchlist card links the call history of the last 10 sessions (the read model keeps 30; the call-history page
  has Earlier / Later links through all 30). The session list is the session being predicted plus the company's
  stored bars before it.
- The news card's help says "first seen in the last 30 days (the newest 50)" (B12's window), not "every stored story".
- Page 04's agreement bars draw the baseline segment, which the mockup's SVG drops (the mockup's `.b` rect class
  clashes with a shared rule; the list under the chart has the same numbers).
- The call-history page (no mockup) shows, for one session D, every prediction with its path (made, checks, settled
  net, notes), the head-to-head picks, every intraday check of those trades, their settlements with the "why" bars and
  the analyst's notes; an older day is the API's 404 with "the history keeps the last 30 sessions".
