# B15, Company pages UI (Wave 4)

## Scope
The Next.js pages 03-company (`/api/v1/markets/{m}/stocks/{t}` plus its bars, trades and per-day lifecycle) and
04-stock-strategies (`/api/v1/markets/{m}/stocks/{t}/strategies`), built from the approved mockups
(`design/mockups/03-company/`, `04-stock-strategies/`) on B12's endpoints, inside B7's app shell. Branch
`build/b15-company-ui`.

## Files
- `web/lib/company-pages/` (pure presentation logic, B7 layout): `types.ts` (the payload fields
  read), `company-logic.ts` (open-trade sums, settled summary, "why" bar parts, chart trade marks, next event),
  `chart-geometry.ts` (price chart scales, fan, targets, spread, ticks), `strategies-logic.ts` (ranking order, best row,
  expected gain in money), `tests/logic.test.ts`.

## Contract
No API or data change. Pages read only `/api/v1` (B12's routes); windows are B12's (news 30 days / newest 50, events
60 days, bars 250 sessions, owner 2026-10-08).
