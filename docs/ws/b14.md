## Contract
No API change. The pages read only their endpoint (B7's `usePage`) and, on the Companies page, POST to B11's
`/api/v1/markets/{market}/companies/preview` and `/companies/commands` (api/paths/companies.yaml). Every request a
dialog sends is confirmed by the owner on the server's own summary; delete also needs the ticker typed
(`arguments.confirm` = the ticker). A recorded request shows as pending on the page until the next run's import makes
it part of the read model. Nothing here trades.

Deviations from the mockups, each because the real routes differ from the mockup's stand-in:
- Add company has no "Name (optional)" field: `add_company` takes `symbol` and `amount` only (mcp/tools.yaml); the
  name comes from the identifier check and is shown in the summary.
- Amount, deactivate, reactivate and delete show the server's summary and a Confirm step before anything is written
  (company commands are confirmed, B5/F8.7); the mockup recorded those in one click.
- The Requests card counts "sent from this page" (requests confirmed in this tab) instead of the mockup's "pending",
  and each shows the receipt's message.
