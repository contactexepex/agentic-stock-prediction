# C2: the reader's daily report and the public brief

Owner request (2026-10-10): the daily report shared in Slack must be understandable in 20 seconds on a phone by a
retail investor, look like the cockpit (B7's design system), and carry more pictures and plain-language meaning.
Owner decision (2026-10-10, relayed by the orchestrator): the Slack link opens the brief as a public read-only page of
the one app, served by the gateway without login; the self-contained HTML file stays attached in Slack as the offline
backup. Research only: nothing on the page is advice ("lean up / lean down", never "buy" or "sell"); paper trades are
SIMULATED records.

## Batch 1: the page (`scripts/marketbrief/presentation/reader/`)
- `gather.py` builds the reader block as of the run's clock (MB_NOW-aware) with the website's readers:
  - B12's `company_sources.published_ranges` (the as-of date's ranges.py rows, whatever a strategy's live_from) and
    `bar_rows`, and `company_history.forecast_history`, which gives the change since the previous run;
  - B10's `horizon_records.scores_asof` (P(up), N+k only, the view's as-of date);
  - the dashboard's regime, bars and weekly-review readers, which give the mood, the benchmark and the paper label.
  - It covers active companies only. Horizons = `contracts.horizons.horizons()` ∩ (1, 3, 5).
- `why.py`: the lean of P(up) (|P - 0.5| < 0.02 none, < 0.05 slight, else clear), the one-line why built from the
  score's points per feature group, and the flags (results within 5 days, BLOCKED, contradicted news of the last 4
  days).
- `paper.py`: once a strategy is live (registry.is_live on the session), B4's open trades summed per company and per
  strategy, and WS4's signal tiers in lean words; before that, the start date only.
- `page.py`, `assets/` and `static.py`:
  - one self-contained file with B7's `tokens.css` + `tokens-dark.css` inlined (light and dark), an icon subset and
    inline JS;
  - a `<noscript>` copy of the numbers for viewers that run no scripts;
  - a robots noindex meta tag.
- `html_report.py` keeps its CLI, outputs and Slack manifest (`session`, `html`, `images`).

## Batch 2: the public brief
- Link: `<gateway>/brief/<market>/<session>-<token>`, where token = the first 32 hex characters (128 bits) of
  HMAC-SHA256(`BRIEF_LINK_SECRET`, `brief:<market>:<session>`). It comes from
  `presentation/reader/links.brief_path(market, session)`, which returns None without the secret.
- The token is deterministic (a rerun gives the same link) and never stored: the repo is public, and `rm.brief` keeps
  only its SHA-256.
- Data: `warehouse/rm_brief.py` writes `rm.brief` (page_key = the session date; payload `BriefPayload`: session,
  token_sha256, html = the committed `reports/<market>/<session>.html`, newest 30 reader pages up to the session being
  predicted). It is written by `warehouse_sync.py` with the existing `MOTHERDUCK_TOKEN`. Without the secret no row is
  written.
- Route: `web/app/brief/[market]/[slug]/route.ts` with `web/lib/brief/brief.ts`.
  - The market and slug are validated before any read.
  - One keyed read of `rm.brief` through B4's `SqlRowStore`, using the gateway's existing `MOTHERDUCK_READ_TOKEN`
    (read-only).
  - The token's SHA-256 is compared in constant time.
  - A wrong or missing token, market or date gives a plain 404; a warehouse outage gives a 503 with no driver text.
  - Response headers: `X-Robots-Tag: noindex, nofollow`, a CSP of `default-src 'none'` (inline style and script
    only, no connections, no forms, no framing), `no-referrer`, `no-store`.
  - No assistant, forms, `/api/v1`, MCP or write path.
- On https the page shows one plain "Open full app" link (config/warehouse.yaml `app_url` + `/<market>`) instead of
  the attached file's neighbour links.
- Gateway allowlist: GET `/brief/{india|us}/{YYYY-MM-DD}-{32 hex}` only (B5's `lib/tools/gateway.ts`).
- Slack link: B6 switches `presentation/report/gather.report_url` to `slack_link_url` (pointed at the gateway) +
  `brief_path(...)` once the route is live, falling back to `<slack_link_url>/<market>` without the secret.
